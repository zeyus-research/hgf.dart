# Example data

`digits.csv.gz`: the test set of the UCI *Optical Recognition of Handwritten
Digits* dataset (E. Alpaydin, C. Kaynak, 1998), as distributed with
scikit-learn (`sklearn/datasets/data/digits.csv.gz`, release 1.5.0). 1797
rows: 64 pixel intensities (an 8×8 image, 0–16) followed by the digit
(0–9).

Licence: CC BY 4.0, <https://doi.org/10.24432/C50P49>.

`wine.csv`: the UCI *Wine* dataset (S. Aeberhard, M. Forina, 1991), as
distributed with scikit-learn (`sklearn/datasets/data/wine_data.csv`, release
1.7.2), with the attribute names as a header row and the cultivar written as
text (`class_0`–`class_2`). 178 rows: 13 chemical measurements of wines from
three cultivars.

Licence: CC BY 4.0, <https://doi.org/10.24432/C5PC7J>.
